# W2-T4 Timeline and Cache Handoff

## Public surface

The `DiscussionTimeline` Swift package exposes:

- `DiscussionAnalysis`, `DiscussionEvent`, and `DiscussionPlaybackState`: discussion-specific Codable/Sendable contracts;
- `DiscussionTimelineEngine`: pure value-type crossing, seek, rewind, dedupe, and video-change logic;
- `DiscussionTimelineCache`: 24-hour actor-backed cache with injected clock and storage;
- `DiscussionCacheStorage` and `DiscussionClock`: deterministic boundaries;
- `FileDiscussionCacheStorage`: atomic JSON persistence; and
- `DiscussionSessionState`: `@MainActor`, `@Observable` state with `AsyncStream<DiscussionEvent>` at `events`.

The engine and models are Sendable and contain no UI, Chrome, networking, or timers. `DiscussionSessionState` is main-actor isolated for direct SwiftUI consumption. Cache/storage operations are async and actor-safe.

## Integration

Add `Packages/DiscussionTimeline` as a local package dependency and link its `DiscussionTimeline` library product to the app target. W3-T2 calls `session.receive(playback)` for each externally observed browser message. W3-T3 iterates `session.events` or observes `latestEvents`. W3-T4 loads validated API/cache results through `session.load(analysis)`.

Default cache location:

```text
~/Library/Application Support/com.ctphack.discussionnotch/DiscussionTimeline/v1/{videoId}.json
```

The filename key is the validated 11-character YouTube `videoId`. Files contain a versioned envelope and use ISO-8601 dates. Writes use Foundation’s atomic data-write option. Reads evict corrupt JSON, unsupported schema versions, contract-invalid content, API-expired entries, and entries stored for 24 hours or longer.

## Replay policy

- Natural forward crossing is exactly `previousTime < triggerTime <= currentTime`.
- Absolute playback deltas greater than 2 seconds are seeks and emit nothing.
- Backward seeks re-arm events at or after the destination timestamp.
- Backward jitter of 2 seconds or less does not re-arm.
- Duplicate/pause updates do not emit without a forward crossing.
- Rapid natural crossings return every crossed event in timeline order; presentation queueing belongs to W3-T3.
- A video change clears the dedupe set. Attaching/re-attaching establishes a cursor without emitting already-passed events.
- No timer extrapolates playback.

## Verification

Run:

```bash
swift test --package-path Packages/DiscussionTimeline
```

Tests cover natural crossing, pause/duplicates, the 4-to-37-minute seek, rewind replay, jitter, rapid events, video change, contract rejection, cache hit/miss, refresh, API expiry, 24-hour expiry, corruption, incompatible schema, and observable event publication.
