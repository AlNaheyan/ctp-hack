# W1-T3 Integration Handoff

## Result

The discussion UX state machine, annotated compact/expanded card wireframes, collision policy, timing behavior, error recovery, and accessibility requirements are defined in `docs/design/discussion-state-machine.md`.

## Approved decisions

- Analysis loading, browser connection, and playback presentation are independent state axes.
- Cards trigger on observed timestamp crossings and never from a local playback clock.
- A delta over 2 seconds is a seek and emits no skipped event.
- Backward seek re-arms only after moving before `startTime - 0.5` seconds.
- Cards display for 6 seconds and queue chronologically up to three.
- Active HUD/user gestures outrank insights; music may be temporarily replaced without losing its state.
- Insight language is deliberately non-verdictal.
- `startTime` powers “Open at,” while `triggerTime` powers notification timing.

## Contract review

W1-T2 contract version 1 contains every required field. No schema addition or naming change is requested.

## Downstream owners

- W2-T4: timing, seek, replay, queue, and cache domain logic.
- W3-T3: cards, accessibility, and notch precedence.
- W3-T4: submission states and typed error mapping.
- W3-T2: browser connection state input.

## Verification

- Every asynchronous state has visible copy and a recovery action.
- Compact and expanded wireframes cover long content.
- Pause, seek, rewind, video change, and rapid events are unambiguous.
- Existing music/HUD/drag/camera behavior has explicit precedence.
- MVP requires no new full settings architecture.
