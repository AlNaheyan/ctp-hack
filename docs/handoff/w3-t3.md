# W3-T3 Discussion Card Handoff

## Integration surface

The app target now links the local `DiscussionTimeline` package. `DiscussionSessionModel.timelineSession` is the shared `DiscussionSessionState` input expected from W3-T2/W3-T4.

`DiscussionPresentationModel.shared` is the dedicated main-actor presentation coordinator. It binds to `timelineSession.events` and also exposes this direct integration hook for fixture or adapter batches:

```swift
DiscussionPresentationModel.shared.receive(events, videoId: analysis.videoId)
```

Playback adapters should keep pause state current by calling:

```swift
DiscussionPresentationModel.shared.setPlaybackPaused(playback.paused)
```

A video/analysis replacement calls `clear()`. UI code must not write HUD, music, or battery values to present an insight.

## Components and behavior

- `CompactDiscussionInsightCard` owns the closed-notch discussion presentation.
- `ExpandedDiscussionInsightCard` renders type, title, summary, optional speaker/evidence, qualitative confidence, queue count, timestamp action, and dismissal.
- `DiscussionRecoveryCard` provides preview fixtures for disconnected, no-transcript, offline, and backend-error states; W3-T4 owns wiring those lifecycle states.
- `DiscussionPresentationQueue` is a tested value type in the local package. It shows the first event, retains the next two, and replaces waiting slot three with the newest rapid event. Visible/queued IDs are deduplicated.

Cards dwell for 8 seconds compactly and 15 seconds when already expanded. Hover, playback pause, a system HUD, and shelf drag/drop freeze the monotonic deadline. Expansion preserves at least 8 seconds; resumption preserves at least 3 seconds. Reduced Motion changes card transitions to opacity-only.

Closed-lane priority is:

1. user shelf drag/drop;
2. volume/brightness/backlight/microphone HUD;
3. discussion card;
4. routine battery/music/idle content.

The card path does not mutate `sneakPeek`, `expandingView`, music, shelf, or battery state. When no event is active, the pre-existing layout path is unchanged.

**Open at timestamp** constructs a validated YouTube watch URL from the analysis `videoId` and `floor(event.startTime)`. Dismiss/Escape advances the queue. Buttons retain Full Keyboard Access focus; VoiceOver receives the untruncated type, title, time, summary, speaker, and confidence description.

## Manual visual checklist

- [ ] Trigger one fixture event while closed; confirm icon, truncated title, and fixed timestamp fit.
- [ ] Hover the compact card; confirm the notch expands and the same event remains visible.
- [ ] Verify a long title uses at most two lines and summary at most three at normal text size.
- [ ] Verify speaker, confidence label, evidence, Open at timestamp, and Dismiss are legible.
- [ ] Queue five rapid events; verify the active event plus earliest two and newest waiting events appear in order.
- [ ] Trigger volume/brightness HUD and shelf drag during a card; confirm the card hides/freezes and resumes afterward.
- [ ] Confirm routine battery/music behavior returns unchanged after the queue empties.
- [ ] Pause/resume YouTube; confirm the deadline freezes and no duplicate card appears.
- [ ] Enable VoiceOver and Full Keyboard Access; verify announcement, focus rings, Escape, Open, and Dismiss.
- [ ] Enable Reduce Motion, Increase Contrast, and a large accessibility text size; verify content remains usable.
